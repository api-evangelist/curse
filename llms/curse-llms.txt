# CurseForge Core API

> CurseForge (Curse Inc., now operated under Fandom / Overwolf) runs the CurseForge platform for game mods, modpacks, and add-ons. The CurseForge Core API is a REST API over the CurseForge catalog — games, categories, mods, files, fingerprints, and Minecraft versions/mod loaders — authenticated with an `x-api-key` header issued from the CurseForge for Studios developer console.

## APIs
- [CurseForge Core API](https://docs.curseforge.com/rest-api/): REST API for games, mods, files, fingerprints, and Minecraft data. Base URL https://api.curseforge.com.
